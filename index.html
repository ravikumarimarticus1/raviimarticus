04 · AI-assisted EDA

AI-Assisted Exploratory Data Analysis: Pair an AI Model with Every EDA Stage

The workflow above already shows the exact AI prompt for each stage of this AI-assisted EDA workflow — the prompts work with all the popular AI tools for data analysis, whether you're pasting them into ChatGPT, Claude, or any AI assistant. Here's how to use ChatGPT for data analysis (or Claude for data analysis) end-to-end — a full AI data analysis session showing generative AI for data analysis and AI in data analytics done responsibly — plus the prompt set you'll reach for most.

A Worked AI-Assisted EDA Session

  1. Frame the problem — ask the model to restate the business question and list the columns it would need to answer it.
  2. Understand the data — paste df.info() / df.describe() output and ask for a plain-language summary plus red flags.
  3. Clean with review — ask for cleaning code with reasoning per step, not just code — then review before running it.
  4. Analyse in layers — univariate → bivariate → multivariate, asking the model to suggest the next question after each answer.
  5. Visualise on request — ask for the chart type suited to the question, not the one that "looks nice."
  6. Turn findings into a narrative — ask the model to convert bullet insights into a one-paragraph executive summary with a recommendation.
Where AI can mislead youAI can describe a pattern confidently even when the sample is too small or the correlation is spurious. Always ask it to state its assumptions and check them against the row count.

    How to Build a Data Analyst Portfolio: Checklist

      Get found: SEO · AEO · GEO

      A great project nobody finds doesn't get you hired. These three checkpoints make sure your write-up actually surfaces — to a recruiter searching Google, to a snippet-style answer box, and to an AI assistant summarising your GitHub to someone else.

      SEO — Search Engine Optimisation. Recruiters search specific terms, not vibes.

      Before

      "My cool notebook"

      After

      "Customer Churn Analysis — Pandas, 7,000 rows, flags an 18% at-risk segment"

      AEO — Answer Engine Optimisation. Put the finding first, not paragraph four.

      Before

      "In this project I explored various aspects of the data and found some interesting patterns worth discussing..."

      After

      "Month-to-month customers churn 3.2x more than annual-plan customers — the single biggest driver found."

      GEO — Generative Engine Optimisation. A vague write-up gets you a vague AI summary.

      Before

      "Built some visualisations and used AI to help with analysis."

      After

      "Cleaned a 7,000-row dataset in Pandas (12% missing values), prompted Claude to draft groupby code, validated drivers with a correlation matrix."
